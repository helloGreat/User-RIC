# gNB Patch Notes

This directory describes the gNB-side modifications used in the User-RIC prototype.

The patches extend the Sionna-RK/OAI gNB to expose additional radio-control parameters, including slice-level resource allocation and UE-level communication-state control.

Modified components include MAC scheduling, slice policy, and UE-level link/adaptation policy modules. The compiled gNB image is not included in this repository; this directory only documents the required source-level modifications.
